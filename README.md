# Foro Académico - Seminario

Repositorio destinado al almacenamiento y organización de los trabajos realizados en el curso **Seminario de Tecnologías de Información** de la Universidad Mariano Gálvez de Guatemala.

Los documentos se encuentran organizados por semana y contienen artículos académicos elaborados en **LaTeX**, siguiendo las condiciones editoriales establecidas para el curso.

## Objetivo del repositorio

Mantener un registro ordenado de los artículos, investigaciones y participaciones desarrolladas durante el curso, incluyendo tanto el código fuente en LaTeX como los documentos finales generados en formato PDF.
